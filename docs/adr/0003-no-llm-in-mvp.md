# No LLM in the MVP

Everything the MVP does (Pairings, Cuisines, Formula suggestions, Pantry input) is deterministic and driven by curated content; there is no LLM. The Cook never meets a blank chat box, the demo works with no API keys, latency or cost, and no generated culinary claim can be wrong. An LLM is most likely to earn a place later in Rescue, where describing a problem in free text is valuable. It should be added only with constrained outputs and a deterministic fallback.
