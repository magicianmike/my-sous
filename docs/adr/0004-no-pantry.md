# No Pantry: one way in, one concept, all state in the URL

The spec had two doors: start from an Ingredient, or start from what you have, kept as a Pantry. The Pantry was built and previewed (`prototype/pantry`), then cut before release. It made the Cook keep a list current before getting any help, added a second set of Ingredients to tell apart from the basket, and pulled MySous toward inventory tracking and away from its purpose: understanding what goes with what, and why. The basket already covers the Cook at the open fridge, who puts in what's in front of them. Without a Pantry, nothing is stored in the browser and every screen's state lives in its URL, so every state can be linked and shared. If an honest "Ready" for what's on hand is missed later, the lightest step is an "I have this" mark on basket Ingredients that lasts the visit, not a stored inventory.
